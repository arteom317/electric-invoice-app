# ⚡ ElectricBill Pro

Aplicație iOS pentru inginerii electrici - gestiune facturi și materiale electrice

## 📱 Cerințe

- iOS 17.0+ (necesar pentru SwiftData)
- Xcode 15.0+
- Swift 5.9+

## 🚀 Compilare

```bash
# Clonează repository-ul
git clone https://github.com/arteom317/electric-invoice-app.git
cd electric-invoice-app

# Deschide în Xcode
open ElectricBillPro.xcodeproj
```

## ✅ Erori SwiftData Rezolvate

Acest proiect este configurat corect cu:
- ✅ iOS Deployment Target: **17.0**
- ✅ Supported Platforms: **iphoneos, iphonesimulator** (doar iOS)
- ✅ Mac Support: **DISABLED** (SUPPORTS_MACCATALYST = NO)
- ✅ @available annotations corecte pe toate modelele SwiftData

Pentru detalii complete, vezi [DOCUMENTATION.md](DOCUMENTATION.md)

## 📊 Funcționalități

- Gestionare facturi
- Adăugare materiale pe fiecare factură
- Persistență automată cu SwiftData
- UI nativ SwiftUI
